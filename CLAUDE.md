# Kombu - Creative Studio Website

## Overview
Multi-page studio website for Kombu (kombu.uk), Ryan's one-person creative studio in Southampton: web design, graphic design, commercial photography, and marketing & infrastructure. Linen tray theme: warm ink outlines around four compartment fills (terracotta, kelp, ochre, mist). Anti-agency positioning, first person singular ("I", never "we"), British English, no em/en dashes anywhere in copy or aria-labels. Never mention AI tooling on the site. Wording: the site calls Kombu a "studio" ("one-person creative studio", "Studio partnership"); Ryan confirmed on 25 September 2026 that this stays. The 11 September "creative service, not creative studio" instruction applied to the advert voiceover only.

## Tech Stack
- **Framework**: Astro 5 (static output). No View Transitions, no `<ClientRouter />`; each page is a full navigation.
- **Animations**: Lenis only (self-hosted at `public/vendor/lenis-1.3.26.min.js` since 27 Sep 2026, pinned; it used to load from unpkg's floating `lenis@1`, which cost a redirect), for scroll smoothing. No GSAP, no ScrollTrigger, no shader. The home page's opening (restored on desktop on 11 October 2026 at Ryan's request, "Desktop opening" in `src/styles/home-preview.css` plus the inline script after the opening in `index.astro`): at 1025px and up the letters land one by one (the old `land` keyframes, oversized and settling) with nothing else on screen; scrolling, the hero lags at about half the scroll speed until it has used up the empty space under it, the four compartments pop in one after another (`pop`), the line fades in, and the nav arrives after the fourth (`data-holds-nav` tells Layout's nav script to wait). It is deliberately NOT a pinned stage: the September pinned version had to fit the wordmark and all four cells in 100vh and broke at half-4K and third-of-4K, so this one keeps content height and measures the lag from the real gap. Phones and tablets keep the static layout with the gentle `home-land`. The old pinned-intro sequence in `Layout.astro` still exists but is inert without `#intro`. The wordmark is sized from its ink (`calc(100cqw / 2.992)`, `margin-left: -0.022em`) so the K and the U sit exactly on the gutters and the K lines up with the line beneath. `prefers-reduced-motion` and the `?nomotion` query flag both add `.no-motion`, which freezes the letter landing, the example-tile hover, the portrait parallax and the recorded work previews, and forces lazy images eager for static captures.
- **Styling**: one stylesheet, `src/styles/site.css`, imported by `Layout.astro`. Since 11 Oct 2026 `astro.config.mjs` sets `build.inlineStylesheets: 'always'`, so every page carries its CSS inline (no render-blocking stylesheet request). CSS custom properties for all colours; never raw hex inside rules. No shadows, no gradients: elevation is a 2px ink outline on every card, tile, pill and image frame, and a hover is a 2px downward translate.
- **Fonts**: Supermassive (display, self-hosted under the CSS family `'Supermassive RS'`: `/fonts/SupermassiveRS-I.woff2` at 700, `/fonts/Supermassive-2.woff2?v=1` at 800, `/fonts/SupermassiveRS-III.woff2` at 900) + Switzer (body) from Fontshare. Since 18 Oct 2026 weight 800 is Supermassive II, the full Frere-Jones release Ryan bought, which replaces Supermassive RS II: same letters, metrics and character set, with every punctuation mark and symbol properly drawn (and since 18 Oct weight I's punctuation is rebuilt from it too, version 1.002, `SupermassiveRS-I.woff2?v=3`: see the forge README; Ryan's hand-drawn `?` below now only lives in III). Never name it `Supermassive-II.woff2` (the trial's file name). Source OTF: `/Volumes/External 2TB/Downloads/Supermassive-10512/Supermassive-II.otf`; desktop family "Supermassive II". The old `SupermassiveRS-II.woff2` stays in `public/fonts` unreferenced. Supermassive RS is Ryan's own licensed cut of Supermassive, made with the original author's permission, with custom-drawn punctuation, so it covers the full character set and needs no fallback face and no `unicode-range`. Bevellier has been removed from the system entirely. The superseded trial files (`Supermassive-*.woff2`) stamp a rotated "TRIAL" watermark over every non-alphanumeric glyph, so if punctuation renders as a tiny rotated word, the wrong file is loaded. The `?` and `¿` are Ryan's own drawing since 11 October 2026 (the constructed one read as janky): the font is built in `/Volumes/External 2TB/Downloads/Claude/supermassive-forge` (README there), his SVGs live in its `src/question-svg/`, and `src/import_svg.py` reads them back. Every reference to the font files carries `?v=2` (Layout, the quotes, `public/nova-quote`), because ryanstanikk.co.uk serves fonts immutable for a year; bump it on the next font change, here and on the other sites. Figma keeps each text layer's shaped glyphs in the file, so after any font update existing text keeps the old shapes until re-laid out: run Plugins › Development › Refresh Supermassive RS text (`~/Design/figma-plugins/refresh-font/`, whole file with nothing selected) in each Figma file, after restarting Figma's font helper (`figma_agent`) if it was running before the update.
- **Mark**: the brand symbol is a four strand knot in the four compartment colours, added 11 September 2026. It is used only as the favicon and app icons (`public/favicon.svg` plus the PNG, ico and maskable set, all versioned `?v=3`); on the page the identity stays the KOMBU wordmark. Master artwork is outside the repo at `Google Drive/Design/Kombu Logos/New-SVG.svg`. The JSON-LD `logo` field points at `/favicon-512.png`, so it now carries the mark too.
- **Deploy**: primary is the `cf-pages-deploy` MCP (`deploy(project_dir="/Volumes/External 2TB/Websites/Website Site/dist", project_name="kombu-web-design")`); fallback if the MCP is unavailable is `wrangler pages deploy ./dist --project-name=kombu-web-design --branch=main --commit-dirty=true` (branch=main is production). No git auto-deploy.

## Architecture notes
- `src/layouts/Layout.astro`: the whole document. Head carries meta/OG/Twitter/geo/PWA/favicons and the JSON-LD base graph (WebSite + ProfessionalService/LocalBusiness + Person) merged with each page's `extraSchema` prop, same props interface as before (`title`, `description`, `canonical`, `ogImage*`, `ogType`, `extraSchema`); body carries every client script (Lenis bootstrap, the legacy pinned-intro sequence which is inert now that the home page has no `#intro`, mobile menu and lightbox) plus the service worker registration. `<slot name="head" />` lets a page add its own head content (the photography page uses it for the Google Places script). A noscript block forces the floating nav visible and collapses the pinned intro's scroll padding, mirroring what `.no-motion` already does, since without JS the nav would otherwise sit permanently at `opacity:0`.
- No separate runtime component: `SiteRuntime.astro`, `Rail.astro`, `BottomNav.astro` and `Loader.astro` are retired. Navigation is `Nav.astro`, a single floating pill nav shared by every page (desktop and mobile alike): white, 2px ink outline, the wordmark left, links centre, a WhatsApp pill right; under 768px the links collapse behind a Menu pill that opens a full-screen tray menu (six filled tiles on linen, the four compartments plus an ink Work tile and a white About tile, contact pills centred beneath). `Footer.astro` is the shared ink lid at the bottom of every page.
- The quote calculator lives inline in `photography.astro` (no separate `QuoteCalculator.astro` component): pricing mirrors ryanstanikk.co.uk `public/assets/calc.js` exactly (ported 27 Sep 2026; that file is the source of truth, so change both together): RATES £275/£415/£690, RATES_LOCAL £220/£330/£550 (local independent, charity or individual, hidden in London or beyond 30 mi, unknown location counts as local), RATES_NATIONAL £385/£580/£965, worldwide 'Quoted individually', multi-day full x days x 0.9; distance multiplier x1.15 from 25 mi (half-day minimum beyond 30), x1.25 beyond 80 and x1.40 beyond 150 (full day only), London x1.40 with half-day minimum; round to the pound; travel and accommodation added at cost as a note, never priced in and never promised free. Since 8 Oct 2026 it also has a Video category (RATES_VIDEO £495/£795/£1,295 from ryanstanikk.co.uk/video, times the same distance bands, no business-type question, no multi-day; added before Other) and an eCommerce product count (up to 15 products: half-day minimum; 16 to 40: full day; over 40: 'Quoted individually', per image). No takeaway multiplier (the photography site has none) and no 'Not sure which to pick?' AI helper (that lives only on ryanstanikk.co.uk). Mirrored in `public/pricing.md` and `public/llms.txt`. London text-detection only applies to postcode-shaped input; coordinates use the bounds check. Maps key is referrer-restricted to kombu.uk + localhost.
- Shared interior-page components: `PageHead.astro` (the opening full-width fill card under the nav, h1 + lede + fact chip + two pills + an image or collage), `Ledger.astro` (ruled plain-label rows, not cards), `Faq.astro` (native `details`/`summary` accordion, no JS), `ContactCard.astro` (the ochre contact card, WhatsApp/call/email pills), `Marquee.astro` (clients marquee).

## Free site check Worker: kombu-site-check
`workers/site-check/` is its own Worker (not part of the Pages build), routed at `kombu.uk/api/site-check*` on the kombu.uk zone. Deploy from that folder with `CLOUDFLARE_ACCOUNT_ID=eaa5033865a9eb8114b1c55577356657 npx wrangler deploy`. Flow: validate the address (public http/https hosts only, every redirect re-checked), fetch the HTML and read facts from the code with HTMLRewriter (phone, booking, ordering, map and PDF links, headings, copyright years, JSON-LD, embeds), take a desktop (1440x900, three screens) and a phone (390x844 at 2x, two screens) snapshot through Browser Run, cut them with the Images binding, pull real-visitor phone speed from the CrUX API, then send it all to Sonnet 5.5 (`claude-sonnet-5-5`, effort medium, JSON-schema output, server-side fallback on) for exactly five findings, each tied to evidence it was given. Before the shot a script scrolls the capture area (so scroll-triggered fade-ins have played; it lifts a pop-up's scroll lock while it does) and pins fixed elements to the first screen. Cookie notices are deliberately never judged (scrolling moves or dismisses them). Expired or suspended hosting gets its own message. Limits: 3 checks per visitor per hour, 50 a day, the same site served from a 24 hour cache (KV `site-check`). Secrets: `ANTHROPIC_API_KEY` (Folio's), `RESEND_API_KEY` (a sending-only key for kombu.uk), `CRUX_API_KEY` (Google, CrUX API only, in the Ryan Stanikk Photography cloud project), `ADMIN_TOKEN` (also in the folder's gitignored `.env`). The email copy goes from design@kombu.uk via Resend with a Bcc to design@kombu.uk. Every check is logged; `sitecheck-log` opens the log table. An `x-admin-token` header skips the cache and limits for test runs, and `"debug": true` with it also returns the screenshots and code facts. Never mention AI on the page or in the email.

## Client quotes: quotes.kombu.uk (separate Pages project)
Private, `noindex` quote documents live in `quotes/<slug>/index.html` and deploy to their **own** Cloudflare Pages project `kombu-quotes` (custom domain `quotes.kombu.uk`), NOT to the main site. Keeps client pricing off kombu.uk and gives each quote a clean URL like `https://quotes.kombu.uk/toqeer/`.

- `build-quotes.mjs` assembles `dist-quotes/` = `quotes/**` plus the shared brand fonts (`public/fonts`) and favicons, so the fonts are never duplicated in the repo. `dist-quotes/` is gitignored.
- `quotes/_redirects` sends the bare subdomain to kombu.uk (there is no quote index); `quotes/robots.txt` disallows everything.
- Quote pages are standalone single-file HTML using the same tokens as the site: Supermassive RS display (uppercase, 800, no fallback face needed), Switzer body, terracotta accent, 8/12/16px radii, and a nine-step type ramp declared in `:root`. Type rules follow the site exactly: h1 line-height 0.8, h2 0.87, h3 0.88, body and links Switzer 300 at 16px. Sticky section headers are only for grid layouts where the heading column sits beside scrolling content, never on full-width headers.
- `public/nova-quote/` stays on the main site because that link was already sent to the client; new quotes go to the subdomain only.
